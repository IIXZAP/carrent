## ต้องทำเมื่อถึงขั้นนั้น

**เช่าต่อ / เลื่อนวันคืน (ขั้น 5)**
- เช่าต่อ: ล็อกแถวการจอง, ปฏิเสธถ้าใบจองเปลี่ยนไประหว่างนั้น, บวกยอดจากค่าล่าสุดใน DB ไม่ใช่ค่าที่อ่านไว้ก่อนหน้า

**ส่งมอบ–รับคืน / เอกสาร (ขั้น 5–6)**
- ฟังก์ชันอ่านจำนวนเงินเป็นคำไทย (`baht_text`) ต้องอ่านตั้งแต่ 1,000,000 ขึ้นไปถูก — มีเทสต์

**แจ้งเตือน / LINE (ขั้น 7)**
- ผู้รับอีเมลต้องเป็นอีเมลธรรมดาเท่านั้น (กัน header injection) ก่อนส่ง SMTP

**ความปลอดภัย**
- หน้ารายชื่อผู้ใช้ห้ามดึง `password_hash` มาด้วย

**หลังบ้าน**
- บล็อกวันรถ: ปฏิเสธถ้าช่วงนั้นทับการจองที่มีอยู่
- เพิ่มงานซ่อมบำรุง: ตรวจว่ามีรถคันนั้นจริง
- บันทึกรถ/ลูกค้า = transaction เดียว
- บันทึก activity log เมื่อปลดบล็อก, เปลี่ยนสถานะเอกสาร, ข้ามงานซ่อมบำรุง
- cron แจ้งเตือนซ่อมบำรุง: ตั้ง `notified_at` หลังเข้าคิวแล้วเท่านั้น
